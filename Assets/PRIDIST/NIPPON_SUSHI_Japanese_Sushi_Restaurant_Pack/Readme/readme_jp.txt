ゲーム・VR・メタバースにお使いいただけるかわいいローポリモデルのパッケージです。
日本のお寿司屋さんを再現することができます。
このパッケージには外装に関するモデルは含まれていません。


特徴:

・すべてのモデルが標準パイプラインとURPに対応
・計56個のプレハブ
・寿司モデルのプレハブ10個
・小道具モデルのプレハブ46個
・すぐに使えるサンプルシーンを同梱
・シーン上にFBXやプレハブをドラッグ＆ドロップするだけで使用可能
・全モデルが12~1184の三角形で構成されており、モバイル端末とVRに最適
・テクスチャサイズは512×512pxで統一
・他のバンドルを購入しなくても、本製品単体で利用可能
・リアルスケールモデル
・自作シェーダーなし
ご購入前にプレビュー画像とパッケージ内容をご覧になり、詳細をご確認ください。
