This package contains cute low poly models for games, VR, and meta-verse.
You can assemble Japanese style sushi restaurant interior.

This package does not include exterior details.


Features:

・All props are ready to use in Standard pipeline and URP
・This package includes 56 prefabs
・10 low poly sushi prefabs
・46 unique low poly prop prefabs
・Includes a ready to use sample scene
・Just drag & drop FBX or prefabs to your scene
・All models composed of 12~1184 tris. Optimized for mobile phone and VR
・All textures are 512×512 pxs
・Can be used without purchasing other bundles
・Real-world scale
・No self made custom shaders
Please see preview images and package content to learn more before purchasing.
