## 既知の注意事項（修正済みバグ）

修正済みのため QA で改めて動作確認する：

| バグ内容 | 確認項目 |
|---------|---------|
| オフライン収益が実際の約 1/50 しか計算されていなかった | → 9-3, 9-5, 9-6 |
| CheckIfICanSave がローカル変数のせいで機能しておらず、起動直後にセーブが走る可能性があった | → 19-6 |
| LevelGauge が極高レベルで NaN になりスライダーが壊れた | → 7-7 |
| Stats パネルの Total Sushi・Prestige Level が翻訳されていなかった | → 15-3 |
| LifeSaveDataManager のキーに ` + ` が混入しており、ライフのセーブが本来のキー規則に従っていなかった | → 10-9 |
| バナナ数が Infinity になった場合に for ループが無限ループするリスク | → 3-5, 20-3 |
